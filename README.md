# Waste Track Complete Web App

React + TypeScript + Tailwind CSS implementation based on the supplied Waste Track UI reference screenshots.

## Included flow
Splash → Login/Signup → Dashboard → Report Waste → QR Scanner / Pin Location → Site Details → Create Report → CNN Analyzing → Review/Submit → Submitted → My Reports → Review Report

Also included:
Calendar → Calendar List → Schedule Details (full / scheduled / empty)

## Run
npm install
npm run dev

## Responsive behavior
Mobile: bottom navigation and single-column app.
Computer: desktop sidebar navigation and centered responsive content.

The files under `src/assets` are cropped reference assets from the supplied screenshots. Replace them with original project assets for production.
